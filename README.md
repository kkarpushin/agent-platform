# Маяк — платформа AI-автоматизации

Рабочий учебный каркас: **девять слоёв одной системы**, понятный интерфейс и отдельные программы-агенты. Компания, сотрудники, цены и кейсы вымышлены. Начните с готового процесса, затем добавляйте своё.

## Запустить

Нужен установленный и запущенный **Docker с Compose v2** (для тестов — 2.24.4 или новее). В открытой папке репозитория:

```bash
docker compose up
```

После готовности сервисов откройте **http://localhost:8080**. Первый запуск скачивает зависимости и может занять несколько минут. Если порт занят: `PORT=8081 docker compose up` в bash или задайте `PORT=8081` в `.env`. `.env` и ключ модели для первого запуска не нужны.

**Первый проход:** Марк → «Процессы» → предложение для «Орбиты», задача «Нужен аудит процесса обработки заявок», бюджет 2400 USD → расчёт 1800 USD и 5 рабочих дней → Анна → проверить и одобрить. Измените текст: потребуется новое одобрение. Модель в деморежиме заменена явным шаблоном; поиск, код агентов, расчёты, доступы, версии и база данных настоящие. Старт не отправляет ничего клиентам.

## Как устроено

| Слой | Где лежит | Что делает человек |
|---|---|---|
| Цели и люди | `config/goals.yaml`, `people.yaml` | Определяет результат и ответственных |
| Роли и полномочия | `config/roles.yaml` | Задаёт разрешённые сведения и действия |
| Знания и информация | `knowledge/` → PostgreSQL | Добавляет источники и проверяет ответы |
| Скиллы | `skills/` | Сохраняет способы работы для повторного использования |
| Агенты и модели | `agents/`, `sdk/client.py` | Выбирает исполнителя и модель |
| Инструменты и доступы | `compose.yaml`, `.env` | Подключает средства и ограничивает действия |
| Процессы | `processes/` + код агента | Задаёт путь от входа до результата |
| Запуск и состояние | `platform/`, PostgreSQL | Видит работу, ожидание, версии и решения |
| Проверка и улучшение | `tests/`, журнал и память | Находит ошибки и проверяет исправления |

Платформа проверяет доступ и хранит историю. Агент выполняет свою логику по договорённому входу и выходу. Знания и модель он получает через платформу с временным пропуском. [Подробная карта и ограничения](docs/architecture.md).

## Развивать

- **Добавить знание — один шаг редактирования:** создайте Markdown-файл по образцу в `knowledge/<раздел>/`; затем Анна нажимает «Синхронизировать» в интерфейсе. Цена и себестоимость хранятся раздельно.
- **Добавить сотрудника — один шаг редактирования:** добавьте запись в `config/people.yaml` с существующей ролью; затем синхронизируйте. Режим демонстрации не проверяет личность сотрудника.
- **Добавить агента:** скопируйте `agents/_template/`, опишите вход/выход, измените код, подключите отдельный сервис Compose и проверьте примеры. [Пошаговая инструкция](docs/add-agent.md).
- **Подключить настоящую модель:** [инструкция](docs/model-and-access.md). Ключ остаётся только у платформы; тарифы задаются явно.

## Проверить и остановить

`make test` запускает отдельный временный стенд без ключа модели и не меняет вашу базу. [Команды без Make и состав проверок](docs/testing.md). Проверки доступа, форматов, повтора, версий, источников и всех примеров агентов находятся в `tests/` и `agents/*/tests/`.

`docker compose stop` останавливает систему. Следующий `docker compose up` сохраняет данные. **Не используйте `down -v`, если хотите сохранить журнал и решения:** эта команда удаляет том базы. Если изменили код агента или интерфейс, запускайте с `--build`.
