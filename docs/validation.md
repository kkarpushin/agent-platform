# Приёмка учебного выпуска v0.1.0

Проверено 19 октября 2026 года на Linux с Docker Compose 2.37.1. Данные студии вымышлены. Проверки относятся к этому выпуску, а не к будущим изменениям участников.

## Автоматические проверки

`sh scripts/test.sh` — **48 passed**, 16,09 секунды. Это команда, которую вызывает `make test`; на авторской машине утилиты Make нет. Стенд использовал отдельный проект `mayak-platform-tests`, настоящий PostgreSQL и два отдельных сервиса агентов. После проверки временный проект и его база удалены. Рабочая база не удалялась.

Проверены доступы, поиск, расчёт, все примеры агентов, повтор запроса, версии, решения, устаревание источников, ошибки синхронизации, отзыв временных токенов и контракт шлюза модели. Одна диагностическая заметка зависимостей: Starlette использует устаревающее имя `BlockingPortal`; ошибок тестов нет.

`python3 tests/browser_schema.py` — успешно: обязательное логическое поле допускает `false`, значения по умолчанию и перечисления сохраняют тип, неподдерживаемая схема объяснена до запуска. JavaScript-ошибок нет. Проверка использует перехваченный API и не пишет в рабочую базу.

## Настоящий запуск и интерфейс

- В браузере открыты девять слоёв. Проверены экраны на ширине 1440, 768 и 390 пикселей; горизонтальных выходов за экран и ошибок JavaScript не обнаружено.
- Марк запустил предложение для «Орбиты»: аудит обработки заявок, бюджет 2400 USD. Код выбрал S01, рассчитано **1800 USD и 5 рабочих дней**. Это проверка одного сценария, а не универсальная оценка качества подбора.
- Результат содержит таблицу расчёта и ссылки на использованные источники. Закрытая себестоимость не попала в результат или трассировку Марка.
- Анна одобрила версию 1; редактирование создало версию 2 и потребовало нового решения. Исходный результат и прежнее решение сохранились.
- Из контейнера агента проверены попытки обратиться к пользовательскому API от имени Анны, включая подмену `X-Forwarded-For`: отказ 403. Внутренний Context API без токена: 401. Соединения с базой, вторым агентом и внешним IP недоступны.

## Что требует отдельной проверки

- Настоящий Anthropic API не вызывался. Протокол, учёт токенов и ошибки проверены контролируемыми ответами; доступ конкретного аккаунта, качество модели и фактический счёт провайдера этим не подтверждены.
- Нет проверки развёртывания на Windows/macOS и корпоративной эксплуатации. Есть команды Compose для запуска без Make.
- Нет семантического поиска, фонового расписания и отправки клиентам. Эти функции описаны как будущие расширения.
- Готовый выпуск и автоматический результат CI можно проверить в [GitHub Actions](https://github.com/kkarpushin/agent-platform/actions). Отчёт CI относится к указанному в запуске коммиту.
