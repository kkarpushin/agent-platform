# Приёмка v0.2.0

Проверки выполнены на Linux 19 октября 2026 года. Все бизнес-данные вымышлены. Рабочая база v0.1 не использовалась и не удалялась.

## Программные проверки

Полный изолированный запуск Compose: **68 проверок прошли**. После него отдельно прошла новая проверка происхождения источников через `workspace`: фактически выданная старая версия сохраняется в трассировке, изменение источника обнаруживается, новое принятие отклоняется. Текущий полный набор содержит 69 проверок; результат запуска опубликован в [GitHub Actions](https://github.com/kkarpushin/agent-platform/actions).

Проверены: PostgreSQL и HTTP-сервисы, роли и разделы, динамический скилл, чтение состояния новым агентом по `workspace: true`, недоступный контекст, форматы, повторы, конкурентные изменения, точная версия решения, сохранение истории, устаревшие источники, повторный разбор с замечанием, очередь CLI и разбор ответов. В этих тестах модельные ответы контролируемые; они не заменяют живые вызовы.

## Настоящие вызовы модели

Авторизованные **Claude Code 2.1.303** и **Codex CLI 0.154.0** проверены отдельно, затем через очередь платформы и реальные агенты. Claude сообщил имя модели в результате; Codex точное имя не сообщил — журнал сохранил это как неизвестное. Денежная стоимость подписочных запросов не выдумана.

Полный цикл на отдельном стенде прошёл 15 проверок: E001 → предложение → решение в учебной роли Анны → TASK-E001 → E002 → новое решение → та же задача версии 2, состояние «готово», две записи истории. Проверены отсутствие изменения до принятия, отказ Марку, повтор события и повтор принятия, отсутствие финансового содержимого, настоящий вызов сводки без изменения задач. Решения в этом прогоне — действия приёмочного теста на вымышленных данных, не решения реальной компании.

Проверка расширяемости: временный `skills/meeting-agenda/SKILL.md` добавлен и синхронизирован; скилл успешно выполнен через Codex явно и через автоматический выбор. Инструкция и версия записаны в вызовах. Хеш кода общего исполнителя до и после совпал. Временный файл затем удалён и синхронизирован; участник добавляет его в упражнении.

## Интерфейс

45 сочетаний страниц и размеров экрана (1440, 768 и 390 пикселей) проверены на работающем API; ошибок JavaScript, HTTP и горизонтальных переполнений не найдено. Проверены четыре роли, девять слоёв, сообщения, доска и история TASK-E001 версии 2. Формы, ручной выбор скилла и повторный разбор с замечанием дополнительно проверены на управляемых API-ответах.

## Границы результата

- Проверка установки и полного запуска на macOS и нативной Windows не выполнялась. В Windows рекомендован единый маршрут через WSL 2; команды установки CLI приведены по официальным источникам.
- Не выполнялась автоматическая репетиция всех 20 промптов урока. Дополнительный агент и второй процесс остаются упражнениями.
- Это проверенная учебная основа. Новые сервисы, корпоративный вход, расписание, чужой недоверенный код и поиск по смыслу требуют отдельной реализации и приёмки.
- Успешный модельный пример не гарантирует правильность всех будущих поручений. Сохранены проверки источников, версий и решение человека.
