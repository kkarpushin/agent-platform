# Настоящая модель и личный доступ

## Модель

Базовый режим `LLM_MODE=demo` не вызывает внешнюю модель. Он нужен для проверки интерфейса, расчётов, прав и истории. Вызовы агента и базы выполняются по-настоящему.

Чтобы подключить Anthropic API:

1. Скопируйте `.env.example` в `.env`.
2. Укажите `LLM_MODE=anthropic`, свой `ANTHROPIC_API_KEY` и доступный вашему аккаунту `ANTHROPIC_MODEL`. Выберите модель по [официальному списку](https://platform.claude.com/docs/en/models/overview). Не вставляйте ключ в чат или репозиторий.
3. Если нужна оценка расходов, укажите `INPUT_PRICE_PER_MILLION` и `OUTPUT_PRICE_PER_MILLION` по тарифу выбранной модели. Значения в USD за миллион токенов. Без тарифов платформа сохраняет число токенов, но не придумывает цену.
4. Выполните `docker compose up -d --force-recreate platform`. Откройте интерфейс и убедитесь, что он показывает настоящую модель. Запустите одну небольшую заявку и проверьте журнал.

Платформа обращается к [Messages API](https://platform.claude.com/docs/en/api/messages/create). Токены берутся из ответа провайдера, а не оцениваются по длине текста. На один запуск установлено ограничение числа обращений. Если ключ, модель или сервис недоступны, запуск завершается ошибкой; демо-ответ не подставляется. Реальные API-вызовы могут стоить денег; условия доступа и оплаты проверяются в аккаунте провайдера.

В стартовых проверках сетевой ответ провайдера заменён контролируемым ответом, чтобы проверить протокол и ошибки. Это не доказательство успешного платного вызова из вашего аккаунта.

## Личный доступ

Для локальной демонстрации входа без переключателя задайте `AUTH_MODE=token`. В `PERSON_TOKENS` укажите JSON-объект: длинный случайный токен → идентификатор сотрудника, например `mark` или `anna`. Создавайте разные токены командой `python3 -c "import secrets; print(secrets.token_urlsafe(32))"` на своей машине. Сохраните их только в `.env`.

После пересоздания платформы интерфейс запросит личный токен. Он хранится в памяти вкладки, а не в исходниках. API принимает `Authorization: Bearer <токен>`. Заголовок `X-Person` в этом режиме не меняет пользователя. Токен запуска агента и личный токен сотрудника — разные пропуска.

Не открывайте учебный сервер в интернет простым изменением адреса порта. Для публикации рабочего сервиса отдельно подготовьте HTTPS, корпоративный вход, защиту и ротацию ключей, лимиты и резервные копии.
