# Проверки без платных вызовов

`make test` запускает отдельный проект `mayak-platform-tests`. Он использует только деморежим, не получает ключ модели, не занимает порт 8080 и не меняет пользовательские запуски. По окончании удаляется только его временная база. Внутри тестов PostgreSQL создаются отдельные случайные схемы.

Для учебного набора используйте Docker Compose 2.24.4 или новее. Тестовая конфигурация использует `!reset` для отключения публичного порта. Обычный запуск приложения требует Compose v2.

## Без Make и shell, например Windows PowerShell

В корне репозитория выполните по очереди:

```text
docker compose -p mayak-platform-tests -f compose.yaml -f compose.test.yaml --profile test up --build -d --wait db client-brief commercial-proposal platform
docker compose -p mayak-platform-tests -f compose.yaml -f compose.test.yaml --profile test run --build --rm tests
docker compose -p mayak-platform-tests -f compose.yaml -f compose.test.yaml --profile test down -v
```

Последняя команда удаляет **только тестовую базу**. Не переносите флаг `-v` в команды своего рабочего проекта.

## Что проверяется

- Настоящие PostgreSQL и оба HTTP-сервиса: источники, суммы, трассировка, повтор запроса, правки и согласование.
- Все примеры `agents/*/tests/cases.json`, кроме `_template`.
- Отказ роли до вызова агента, закрытые записи, необъявленный раздел, просроченный токен, неправильный формат выхода.
- Неизменяемая история, устаревший источник, безопасный отказ синхронизации.
- Протокол настоящего провайдера с контролируемым тестовым ответом: учёт токенов, неполный ответ, лимиты и отсутствие подмены демо-ответом.

HTTP-набор дополнительно проверяет режим сервера **до первого запуска**. Если указать настоящий API через `BASE_URL`, набор остановится без вызова агентов.

Браузерная проверка форм хранится в `tests/browser_schema.py` и запускается отдельно при установленном Playwright. Результаты авторской приёмки — в `docs/validation.md`. Они относятся к указанной версии, не к произвольным будущим правкам.
